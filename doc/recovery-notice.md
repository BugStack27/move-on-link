# 中断恢复提示改为常驻可回查 - 任务规划

## 需求概述

迁移中途关闭程序后，下次启动只在启动时闪一条约 8 秒的 toast，内容涉及残留副本、备份或待检查日志的路径，错过就再也查不到。本次把恢复结论改为选择页上的常驻提示卡片：完整展示所有相关路径，支持一键打开所在目录，用户确认后主动关闭；提示落盘保存，未关闭时重启仍可看到，关闭后删除。

## Requirements

### 1. 后端输出结构化恢复提示并持久化

| 属性 | 值 |
|------|-----|
| **目标** | `recover_interrupted` 返回结构化提示（级别、标题、说明、路径列表，路径区分目录/文件）；提示写入 app data 的 `recovery-notice.json`，未关闭前重启仍能读到；新增读取与关闭命令，关闭时删除落盘文件 |
| **涉及文件** | `src-tauri/src/model.rs`、`src-tauri/src/engine.rs`、`src-tauri/src/lib.rs` |
| **验收标准** | `cargo test` 通过（含中断恢复用例）；启动有新提示时覆盖落盘，无新提示时回读上次未关闭的提示；`recovery_notice` 返回结构化数据，`dismiss_recovery_notice` 清除内存与文件 |
| **依赖** | 无 |

### 2. 选择页常驻提示卡片

| 属性 | 值 |
|------|-----|
| **目标** | 选择页（Step 01）顶部展示常驻提示卡片：标题、说明、完整路径（自动换行、可选中），目录提供「打开」、文件提供「打开目录」，右上角关闭；不再使用 toast 展示恢复提示 |
| **涉及文件** | `index.html`、`src/main.js`、`src/styles.css` |
| **验收标准** | 启动后卡片常驻于选择页，完整路径不被截断；「打开」能定位目录；关闭后卡片消失且后端落盘清除，再次启动不再出现 |
| **依赖** | 1 |
